## [Mistral 发布 1 万亿参数开放权重前沿模型](https://www.producthunt.com/products/mistral-7b) ⭐️ 9.0/10

Mistral 发布了 Mistral Large 4，这是一个拥有 1 万亿参数、490 亿激活参数的模型，在其自有的 3,800 块 NVIDIA Grace Blackwell GPU 集群上训练完成。该模型预览版已通过 Mistral API 提供，并承诺在月底前开放权重。 这是开源 AI 的一个重要里程碑，因为 1 万亿参数的开放权重前沿模型大幅提升了整个社区可获取的能力上限。这也标志着 Mistral 重回竞争行列，大约落后最前沿水平六个月。 该模型通过 Mistral API 仅支持两种推理级别，即“none”和“high”，在 Artificial Analysis 上得分为 38，仅次于 552B 的 DeepSeek 4.1 Flash。相比去年 12 月的 Mistral Large 3（同一基准上仅得 9 分），这是一次巨大的提升。

rss · Product Hunt (AI应用) · 10月6日 15:07

**背景**: Mistral Large 4 是一个混合专家（MoE）模型，意味着它总共有 1 万亿参数，但每个 token 只激活 490 亿参数，这使得推理成本远低于同等规模的稠密模型。它是在 NVIDIA Grace Blackwell GPU 上训练的，这是一种将 Grace CPU 与 Blackwell GPU 结合的新一代超级芯片架构。开放权重模型会公开其训练好的参数，任何人都可以下载、运行和微调，而闭源模型只能通过 API 访问。

## [Anthropic 发布 Claude Haiku 5.5，采用全新分层定价](https://www.anthropic.com/claude-haiku-5-5) ⭐️ 8.0/10

Anthropic 发布了 Claude Haiku 5.5，称其是迄今为止最便宜、最快、能力最强的小型模型，面向高并发、对成本敏感的任务。此次发布引入了新的分层定价结构，并为 Max 和 Team 订阅用户提供每月 API 额度，在 Hacker News 上引发了广泛讨论。 作为 Claude 5.5 代际中的 Haiku 层级，该模型面向需要廉价、快速推理的智能体和高并发工作负载的开发者，而新的定价与额度方案可能重塑团队为 AI 功能做预算的方式。社区反应表明，这些变化将显著影响个人开发者和企业订阅用户。 定价按提示长度分层：提示不超过 10 万 token 时，输入为每百万 token 0.10 美元、输出为 0.50 美元；超过该阈值后分别升至 0.50 美元和 2.50 美元，一些评论者认为这一门槛对智能体工作负载而言异常低。Max 5x 订阅用户每月可获得 100 美元 API 额度，Max 20x 用户为 200 美元，Team 订阅用户则最多可获得 500 美元并在用户间共享。

## [OpenAI 公布前沿模型求解开放数学问题的新成果](https://openai.com/index/sharing-ai-progress-in-mathematics) ⭐️ 8.0/10

OpenAI 公布了其内部前沿模型在开放数学问题上取得的新结果，并在 GitHub 上公开了 Lean 证明形式化文件与研究细节。据媒体报道，此次发布包含数百项结果，《科学美国人》提到该模型输出了 372 项成果。 这标志着 AI 从解决已知问题转向可能贡献新的数学结果，而 Lean 形式化文件为研究社区提供了可机器验证的产物。它表明前沿推理模型正成为形式数学中可信的工具，对数学家、证明工程师和 AI 研究者都有影响。 这些结果来自一个未公开命名的内部前沿推理模型，而非已公开发布的模型，随附的 Lean 形式化文件允许对证明进行独立的机器检查。研究细节与产物托管在 GitHub 上，但模型本身并未对外开放。

rss · OpenAI Blog · 10月6日 12:00

**背景**: Lean 是一个基于依赖类型论的开源证明助手和函数式编程语言，其证明与定义可被机器检查，近年来在数学界的使用迅速增长。开放数学问题是检验 AI 推理能力的绝佳测试，因为没有已知答案可供记忆，需要搜索、综合、构造证明并进行形式化验证。FrontierMath: Open Problems 和 UnsolvedMath 等基准正是为评估 AI 在这类未解问题上的表现而建立的。

## [数学家对 AI 解决 Barnette 猜想表达复杂情感](https://simonwillison.net/2026/Oct/7/jake-boggan/) ⭐️ 8.0/10

OpenAI 在 GitHub 上的数学仓库将 Barnette 猜想列为第 180 号问题，并提供了 Lean 证明，表明 AI 系统解决了一个长期未解的图论难题。为此问题投入 24 年心血的数学家 Jake Boggan 在 Hacker News 上评论说，这个消息让他感到悲伤和茫然。 这标志着 AI 驱动的数学发现又一座里程碑，表明机器学习和自动定理证明能够攻克人类数十年未能解决的问题。它引发了关于人类数学家角色、研究者情感代价以及 AI 辅助证明中荣誉归属的深刻问题。 该证明在 Lean 中形式化，Lean 是一个基于依赖类型论的证明助手，并托管在 OpenAI 的公开数学仓库中。Barnette 猜想断言每个 3-连通三次平面二部图都是哈密顿图，尽管有 Bagheri 等人（2021 年）和 Gorsky 等人（2022 年）的部分结果，该猜想此前仍未解决。

rss · Simon Willison · 10月7日 04:47

**背景**: Barnette 猜想是图论中关于哈密顿回路的问题——即访问每个顶点恰好一次的路径——针对某些每个顶点有三条边且为二部图的平面图。该猜想由 David W. Barnette 提出，已悬而未决数十年。Lean 是一个开源证明助手和函数式编程语言，用于形式化验证数学证明，已成为 AI 系统进行自动定理证明的关键工具。
