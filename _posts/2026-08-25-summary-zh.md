## [将 SQLite 数据库变成可执行的 Linux 二进制文件](https://simonwillison.net/2026/Aug/24/your-executable-is-a-sqlite-database/) ⭐️ 8.0/10

Farid Zakaria 展示了一种技术，可以创建直接作为 Linux 二进制文件执行的 SQLite 数据库文件。通过将 SQLite 应用程序 ID 设置为 'SELF'，并将 ELF 组件存储在表中，自定义解释器可以提取并运行该可执行文件。 这一技巧模糊了数据文件与可执行文件之间的界限，可能催生新颖的分发和打包方式。它展示了深厚的系统编程知识，并可能激发对 SQLite 文件格式的创造性使用。 该技术利用 SQLite 文件格式中偏移量 68 处的 4 字节应用程序 ID，将其设置为 'SELF'（结构化可执行与可链接格式）。ELF 组件按照特定模式（schema）排列到 SQLite 表中，并由 'self-exec' 解释器（C 代码）提取并执行。Linux 的 binfmt_misc 可以配置为自动调用该解释器来处理匹配此模式的文件。

rss · Simon Willison · 8月24日 11:38

**背景**: SQLite 是一种广泛使用的嵌入式数据库，将数据存储在单个文件中，其格式包含一个应用程序 ID 字段，用于标识文件类型。ELF（可执行与可链接格式）是 Linux 上可执行文件的标准二进制格式。binfmt_misc 是 Linux 内核的一项功能，允许通过将自定义二进制格式与用户空间解释器关联来执行它们。
