## [Wrapture: New Python Library for Tracing and Testing](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) ⭐️ 7.0/10

Graham Dumpleton, creator of wrapt and mod_wsgi, has released wrapture, a new Python library that extends wrapt's monkeypatching capabilities to enable tracing and overriding of function calls. The library supports OpenTelemetry and offers a configuration-based approach to add tracing to existing projects. Wrapture provides a potential alternative to unittest.mock for testing and offers a powerful tracing mechanism for observability, which could benefit Python developers in debugging and monitoring applications. Its configuration-driven tracing could simplify adding observability to legacy or third-party code. Wrapture is very young, only a few weeks old, and is Graham's first large entirely AI-driven project, with all code and documentation written by an AI assistant under his direction. It includes OpenTelemetry support and a TOML-based configuration for capturing traces, as well as a Python API for stubbing in tests.

rss · Simon Willison · Aug 31, 23:59

**Background**: Monkeypatching is a technique in Python that allows modifying the behavior of functions or methods at runtime, often used in testing and debugging. wrapt is a well-known library that provides a transparent object proxy for creating function wrappers and decorators, focusing on correctness. Wrapture builds on these ideas to provide a unified approach for tracing and testing, potentially simplifying how developers instrument and test their code.

## [Latent Reasoning Landscape in 2026: Five Families Mapped](https://www.reddit.com/r/MachineLearning/comments/1w4evwo/latent_reasoning_landscape_in_2026_mapping_bdhcq/) ⭐️ 7.0/10

A Reddit post by user Typical-Scene-5794 provides a detailed taxonomy of latent reasoning methods in 2026, categorizing them into five distinct families: continuous thoughts in autoregressive LMs (e.g., Coconut), compressed discrete non-linguistic tokens (e.g., Abstract-CoT), recurrent depth and looped models, task-trained recursive solvers (e.g., HRM, TRM), and in-context recurrent latent solvers (e.g., BDH-CQ). The post argues that the path to AGI may depend more on reasoning beyond the token stream than on generating ever-longer chains of thought. This taxonomy is significant because it organizes a rapidly growing field and highlights a critical shift in AI research: moving away from token-based chain-of-thought reasoning toward latent reasoning, which could be more efficient and scalable. The post also raises important questions about interpretability and safety, as latent reasoning may sacrifice the readable traces that current evaluation and safety work depends on. The post references specific papers and models: Coconut (Hao et al., 2024), Soft Thinking (Zhang et al., 2025), Abstract-CoT (Ramji et al., 2026), recurrent-depth LMs (Geiping et al., 2025), looped Transformers (Saunshi et al., 2025; Zhu et al., 2026), HRM (Wang et al., 2025), TRM (Jolicoeur-Martineau, 2025), and BDH-CQ (Engdahl et al., 2026). BDH-CQ is highlighted for achieving a point beyond the previously published cost-accuracy Pareto frontier on ARC-AGI-1 and showing transformer-like scaling laws up to 600B parameters. The post also distinguishes between how systems acquire new tasks (context, memory, gradient-based optimization) and where intermediate computation happens (language tokens, abstract tokens, continuous latent states).

reddit · r/MachineLearning · /u/Typical-Scene-5794 · Sep 1, 15:14

**Background**: Latent reasoning is an alternative to chain-of-thought (CoT) reasoning, where instead of verbalizing every intermediate step, the model repeatedly transforms its continuous hidden state and decodes only the final answer. This approach is motivated by observations that LLMs often produce flawed or fabricated CoT steps yet still arrive at correct answers, suggesting that verbalized CoT is an imitation of reasoning rather than the mechanism itself. The field has gained traction with models like Coconut, which feeds the model's own hidden state back as input, and has expanded into various families as described in the post.
