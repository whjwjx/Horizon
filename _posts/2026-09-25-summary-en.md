## [Bastardica: A Web Tool That Mixes Fonts via OpenType Ligatures](https://bastardica.mitpit.com/) ⭐️ 7.0/10

A new Show HN project called Bastardica (bastardica.mitpit.com) lets users create "cursed" mixed fonts, such as Times New Bastard, by abusing OpenType's ligature feature. It runs entirely client-side in the browser by loading Python through WebAssembly, making it fast enough for interactive use. This tool demonstrates a clever, unconventional use of OpenType ligatures and shows how Python-in-WASM can power fast, fully client-side web applications without a server backend. It also highlights how typographic features intended for legitimate design purposes can be repurposed for humor and creative experimentation. The tool works by defining ligatures that substitute characters from one font with glyphs from another, effectively mixing typefaces at the glyph level. Because it relies on Python compiled to WebAssembly, all font processing happens locally in the browser, avoiding uploads or server round-trips.

hackernews · MitPitt · Sep 23, 22:53 · [Discussion](https://news.ycombinator.com/item?id=49823738)

**Background**: OpenType is a font format that supports advanced typographic features, including ligatures, which replace sequences of characters with a single glyph (like "fi" becoming a single connected character). Times New Bastard is a well-known joke font that renders Times New Roman but makes every seventh letter jarringly sans-serif, originating from a Tumblr thread. WebAssembly (WASM) is a binary instruction format that lets languages like Python run in the browser at near-native speed, with projects like Pyodide enabling this.
