## [Datasette 1.0a38 Fixes SQL Injection in Mixed Public/Private Table Setups](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 8.0/10

Datasette 1.0a38 fixes a SQL injection security issue that affects instances serving a mixture of public and private tables in the same database. The fix is also backported to Datasette 0.65.3. This security fix is important because it prevents unauthorized read-only access to private data in mixed-table Datasette instances. Administrators are advised to disable the execute-sql permission to mitigate the issue, highlighting the need for careful permission configuration. The vulnerability allowed users with access to any public table to execute SQL injection attacks, bypassing the execute-sql restriction. The affected configuration is considered rare, but administrators serving private tables should disable execute-sql on the database to prevent access.

**Background**: Datasette is a tool for publishing data as an interactive website, with a permissions system that controls access to tables and SQL queries. The execute-sql permission governs whether users can run raw SQL queries, and the vulnerability allowed bypassing this restriction in mixed public/private table setups.

## [Framework notifies all customers of data breach exposing PII](https://techcrunch.com/2026/08/07/computer-maker-framework-notifies-all-customers-of-a-data-breach/) ⭐️ 7.0/10

Framework Computer has notified all of its customers that hackers accessed their names, email addresses, phone numbers, and physical addresses in a data breach. The company disclosed the incident on August 7, 2026, via a notice to its entire customer base. This breach is significant because it affects the entire customer base of a well-known hardware startup, exposing sensitive personal information that could be used for identity theft or phishing. It underscores the ongoing risks that even security-conscious companies face in protecting customer data. The compromised data includes names, email addresses, phone numbers, and physical addresses, but no financial or password information was mentioned in the notice. Framework has not yet disclosed the attack vector or the number of affected customers, and it is advising customers to be vigilant against phishing attempts.
