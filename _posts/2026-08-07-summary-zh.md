## [Datasette 1.0a38 修复混合公开/私有表设置中的 SQL 注入漏洞](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 8.0/10

Datasette 1.0a38 修复了一个影响同一数据库中同时提供公开和私有表的实例的 SQL 注入安全问题。该修复也已移植到 Datasette 0.65.3。 此安全修复非常重要，因为它防止了在混合表 Datasette 实例中未经授权对私有数据的只读访问。建议管理员禁用 execute-sql 权限以缓解该问题，这凸显了谨慎配置权限的必要性。 该漏洞允许有权访问任何公开表的用户执行 SQL 注入攻击，从而绕过 execute-sql 限制。受影响的配置被认为较为罕见，但提供私有表的管理员应禁用数据库上的 execute-sql 权限以防止访问。

rss · Simon Willison · 8月6日 18:24

**背景**: Datasette 是一个将数据发布为交互式网站的工具，其权限系统控制对表和 SQL 查询的访问。execute-sql 权限管理用户是否可以运行原始 SQL 查询，而该漏洞允许在混合公开/私有表设置中绕过此限制。
